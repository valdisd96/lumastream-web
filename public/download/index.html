A simple first install

  1. Download the APK. On a TV, transfer the file to your TV and open it with a file manager or APK installer.
  2. If Android asks, allow installation from unknown sources for the app opening the APK.
  3. Install LumaStream. You can turn that installation permission off afterward.
Updating a signed release? Install over it without uninstalling to keep settings and history. Debug builds use a different signing key. Uninstalling erases local data — do not uninstall simply to dismiss a signature error.

Verify your download

Place the APK and SHA256SUMS in the same folder. On macOS, run:

shasum -a 256 -c SHA256SUMS

On Linux:

sha256sum -c SHA256SUMS

Install with ADB

For an already authorized device. Replace DEVICE with its identifier from adb devices:

adb -s DEVICE install -r lumastream-0.9.1-universal.apk

A preview, not a compatibility guarantee

Four architectures are packaged. Playback has been exercised on XGIMI Android TV and ARM64 emulators; physical phone/tablet playback and x86 runtime have not been verified. Sources, codecs and device filesystem support still matter.
