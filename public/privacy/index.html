Counting visits. Not following people.

No advertising trackers, cookies or fingerprinting.

What this website measures

  • Successful page requests, grouped by page and language.
  • Redirects to the APK and checksum file, counted separately.
  • Aggregate HTTP errors, response times and service health.
  • Release asset download counts supplied by GitHub.

These are not unique visitor counts. Repeat visits and undetected bots can be counted. Known bots, prefetch, HEAD requests, assets and health probes do not count as page views. A download redirect is not a completed download or an installation.

What the application does not retain

The website application does not store IP addresses, user agents, referrers, visitor IDs or individual event records. It uses no cookies, localStorage or client-side analytics script. Fonts and images do not require third-party requests.

Network infrastructure necessarily processes your address to deliver requests. Keeping IPs out of application analytics does not make the entire network connection anonymous.

Where the counts live

Cumulative aggregates are kept on persistent website storage until removed by the operator and survive restarts. Operational Prometheus time series have 48-hour retention. Grafana access is private; there is no public statistics API.

Downloads and external links

Downloads redirect your browser to GitHub, which receives the request and applies its own privacy policy. GitHub counts include downloads from all origins, not just this website. Links to TMDB and other services open their own websites. GitHub privacy ↗

What about the Android app?

This page describes the website; it does not promise anonymous torrent traffic. Peers see your network IP and enabled optional services receive requests. History and settings remain local to your device.
