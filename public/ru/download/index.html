Установка без лишних шагов

  1. Скачай APK на устройство. Для ТВ сначала перенеси файл на телевизор и открой его файловым менеджером или установщиком APK.
  2. Если Android попросит, разреши установку неизвестных приложений только для приложения, открывающего APK.
  3. Установи LumaStream. После установки разрешение можно отключить.
Обновляешь подписанный релиз? Устанавливай поверх, без удаления: настройки и история сохранятся. Debug-сборка подписана другим ключом. Удаление приложения стирает локальные данные — не удаляй его просто ради обхода ошибки подписи.

Проверь скачанный файл

Помести APK и SHA256SUMS в одну папку. В macOS выполни:

shasum -a 256 -c SHA256SUMS

На Linux:

sha256sum -c SHA256SUMS

Установка через ADB

Для уже авторизованного устройства. Замени DEVICE идентификатором из adb devices:

adb -s DEVICE install -r lumastream-0.9.1-universal.apk

Это preview, не гарантия совместимости

В APK есть четыре архитектуры. Реальные проверки проводились на XGIMI Android TV и ARM64-эмуляторах; воспроизведение на физических телефонах/планшетах и x86 не проверено. Источники, кодеки и файловая система устройства влияют на результат.
