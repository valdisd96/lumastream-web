01 / Установи приложение

Скачай подписанный APK и установи его на Android 9+. Скачать и проверить контрольную сумму →

02 / Начни без аккаунта

  1. На главном экране выбери Open magnet / torrent.
  2. Вставь magnet-ссылку, HTTPS-ссылку на .torrent или выбери .torrent-документ.
  3. Если в торренте несколько файлов, выбери нужное видео. Дождись получения метаданных и первых частей.

На ТВ без системного выбора документов используй ссылки или файловый менеджер. Скорость старта зависит от пиров и соединения — фиксированного времени нет.

Используй только разрешённый контент. BitTorrent может отправлять данные пирам, которым виден твой сетевой IP. Встроенные фильмы, ключи и гарантированные источники не предоставляются.

03 / Каталог — по желанию

TMDB по умолчанию выключен. Он предоставляет описания и изображения, а не видеопотоки.

  1. Создай аккаунт TMDB и запроси API-доступ в API settings ↗.
  2. Скопируй API Read Access Token, а не короткий API key.
  3. В LumaStream открой Settings → Catalog: TMDB, вставь токен, выбери язык каталога и нажми Save settings.
  4. Открой Search или Discover, выбери фильм. Для сериала сначала выбери сезон и эпизод. Нажми Find sources.

Поиск источников использует отдельного Stremio-совместимого провайдера, изначально Torrentio. Дополнительные провайдеры включаются отдельно. Наличие фильма в каталоге не гарантирует источник и не даёт разрешения на скачивание.

Токен остаётся в приватных настройках приложения. Не публикуй его в скриншотах. Выключение сервиса сохраняет ключ, но прекращает запросы к этому сервису.

04 / Управление просмотром

  • TV: OK — пауза/продолжить; Left/Right — перемотка; Up — субтитры; Down — действия плеера. Back закрывает меню или выходит из просмотра.
  • Телефон / планшет: коснись видео для управления. Используй шкалу времени, меню аудио и CC. Поворот экрана сохраняет текущий сеанс.
  • Выбор источника: выбери вручную либо Watch automatically… и группу качества/языка. При ошибке попробуй другой источник.

Субтитры и кэш

Встроенные дорожки, подходящие субтитры в торренте и импорт SRT/WebVTT не требуют аккаунта. Онлайн-поиск OpenSubtitles требует отдельной настройки провайдера и не готов к работе сразу после установки.

В Settings выбери кэш 1, 2, 4 или 8 GiB. Continuous prefetch заранее получает части видео во время просмотра, буферизации и паузы, не выходя за бюджет. Сохрани настройки через Save settings. Доступное место может уменьшить фактический лимит.

Вернись к любимому

Watch later хранит список на будущее, History — просмотренные фильмы и позиции эпизодов каталога. Всё локально на устройстве, без синхронизации. При выходе загрузка останавливается и кэш удаляется; повторный запуск может снова буферизовать. Прямые торренты и Archive не создают историю каталога.
