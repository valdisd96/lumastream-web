LumaStream / Getting started

From install to the first frame.

No mandatory accounts. An optional catalog when you want one.

01 / Install the app

Download the signed APK and install it on Android 9 or newer. Download and verify the file →

02 / Start without an account

  1. On Home, select Open magnet / torrent.
  2. Paste a magnet link or HTTPS torrent URL, or select a .torrent document.
  3. If the torrent contains multiple files, choose your video. Allow time for metadata and the first pieces to arrive.

On TVs without a system document picker, use links or a file manager. Startup depends on peers and your connection; there is no fixed startup time.

Use only authorized content. BitTorrent can upload to peers, who can see your network IP. Films, credentials and guaranteed sources are not included.

03 / Connect a catalog, if you want one

TMDB starts off. It supplies descriptions and artwork, not video streams.

  1. Create a TMDB account and request API access in its API settings ↗.
  2. Copy the API Read Access Token, not the shorter API key.
  3. In LumaStream, open Settings → Catalog: TMDB, enter your token, choose a catalog language and select Save settings.
  4. Open Search or Discover and choose a title. For a series, choose a season and episode first. Select Find sources.

Source lookup uses a separate Stremio-compatible provider, initially Torrentio. Additional providers are opt-in. A catalog entry neither guarantees an available source nor grants download permission.

Your token stays in the app’s private settings. Do not include it in screenshots. Switching a service off retains its key but stops requests to that service.

04 / Take control of playback

  • TV: OK pauses/resumes; Left/Right seek; Up opens subtitles; Down moves to player actions. Back dismisses a menu or leaves playback.
  • Phone / tablet: tap the video for controls. Use the timeline, audio menu and CC. Rotation keeps the current session.
  • Source choice: pick manually, or choose Watch automatically… and a quality/language group. Try another source if one fails.

Subtitles and cache

Supported embedded tracks, matching torrent subtitles and SRT/WebVTT import need no account. Online OpenSubtitles search requires separate application-provider setup and is not ready out of the box.

In Settings, choose a 1, 2, 4 or 8 GiB cache. Continuous prefetch fetches ahead while playing, buffering and paused within that budget. Select Save settings. Available disk space can reduce the effective limit.

Pick up where you left off

Watch later saves titles for later; History retains catalog movies and per-episode resume points. Data stays on this installation, with no cross-device sync. Leaving stops downloads and clears the cache, so resuming may buffer again. Direct torrents and Archive do not create catalog history.
